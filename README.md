# STM32F401 OLED SSD1306 Smooth Logo Rotation

Анимация плавного вращения векторно-растрированного логотипа СПбГЭТУ «ЛЭТИ» (буква «е» с исторической надписью «1886») на монохромном графическом OLED-дисплее SSD1306 ($128 \times 64$) по интерфейсу $I^2C$ в режиме Fast Mode ($400\text{ кГц}$).

Разработано под микроконтроллер **STM32F401CCU6** («Black Pill») на базе архитектуры **CMSIS** (без громоздких библиотек HAL).

---

## 🚀 Особенности проекта

- **Ультраплавное вращение (60 фаз / 33 FPS)**:
  - 60 предрассчитанных кадров с угловым шагом всего **$6^\circ$** по часовой стрелке.
  - Поворот рассчитан строго вокруг истинного геометрического центра эмблемы.
- **Оптимизация памяти (Zero RAM Overhead)**:
  - Все 60 кадров ($60 \times 1024\text{ байта} = 60\text{ КБ}$) размещены в секции `.rodata` Flash-памяти программ (`static const`).
  - Оперативная память (SRAM) под буфер кадров **не расходуется вообще** ($0\text{ байт}$ RAM).
- **Высокая скорость передачи без строчных волн и разрывов**:
  - Шина $I^2C$ переведена в режим **Fast Mode ($400\text{ кГц}$)**.
  - Постраничная пакетная передача: данные страницы (128 байт) передаются одной непрерывной $I^2C$-транзакцией без накладных расходов на побайтовый перезапуск шины.
- **Точные задержки**:
  - Аппаратный системный таймер **SysTick** настроен на прерывание с периодом $1\text{ мс}$ от максимальной частоты ядра $84\text{ МГц}$ (PLL от кварца $25\text{ МГц}$).
  - Безопасная функция задержки с защитой от переполнения 32-битного счетчика тиков.

## 🛠 Аппаратное подключение

| Дисплей OLED SSD1306 ($128 \times 64$) | STM32F401CCU6 (Black Pill) | Описание |
| :--- | :--- | :--- |
| **GND** | **GND** | Общий провод питания |
| **VCC** | **3.3V** | Питание дисплея |
| **SCL** | **PA8** (I2C3_SCL, AF4) | Тактовая линия $I^2C$ (Open-Drain + Pull-Up) |
| **SDA** | **PB4** (I2C3_SDA, AF9) | Линия данных $I^2C$ (Open-Drain + Pull-Up) |

> **Примечание:** Линии $I^2C$ настроены в режим Open-Drain со встроенной подтяжкой `PUPDR`. Для максимальной стабильности на $400\text{ кГц}$ рекомендуется наличие внешних резисторов подтяжки $4.7\text{ кОм}$ к линии $3.3\text{V}$ (на большинстве готовых модулей SSD1306 они уже распаяны на плате).

## 📁 Структура проекта

```text
├── Inc/
│   ├── i2c.h                 # Инициализация I2C3 Fast Mode и функции записи
│   ├── init.h                # Конфигурация тактирования PLL 84 МГц и FPU
│   ├── logo_leti_anim_24.h   # Прототипы функций воспроизведения анимации
│   ├── main.h                # Основные заголовочные зависимости
│   ├── ssd1306.h             # Команды и базовая инициализация дисплея
│   └── systick.h             # Системный таймер и счетчик миллисекунд
├── Src/
│   ├── i2c.c                 # Реализация I2C3 на 400 кГц
│   ├── init.c                # Настройка HSE -> PLL -> 84 МГц, Flash Latency 2WS
│   ├── logo_leti_anim_24.c   # Массив 60 кадров во Flash и отрисовка
│   ├── main.c                # Точка входа main()
│   ├── ssd1306.c             # Инициализация контроллера SSD1306
│   └── systick.c             # Прерывание SysTick_Handler и delay_ms()
├── Startup/
│   └── startup_stm32f401ccux.s # Таблица векторов и ассемблерный стартап
├── STM32F401CCUX_FLASH.ld    # Скрипт компоновщика (Linker Script)
├── .cproject, .project       # Проектные файлы Eclipse / STM32CubeIDE
└── .gitignore                # Исключение сборочного мусора (Debug, .o, .elf)
```

## 💻 Сборка и запуск на другом компьютере

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/<ваш_логин>/<имя_репозитория>.git
   ```
2. **Откройте STM32CubeIDE**:
   * Нажмите `File` $\rightarrow$ `Import...`
   * Выберите `General` $\rightarrow$ `Existing Projects into Workspace` $\rightarrow$ `Next`
   * В поле `Select root directory` укажите папку склонированного проекта.
   * Нажмите `Finish`.
3. **Соберите проект**:
   * Нажмите сочетание клавиш `Ctrl + B` (или кнопку с молотком на панели инструментов).
4. **Прошивка**:
   * Подключите программатор ST-Link к плате и компьютеру.
   * Нажмите значок **Run** или **Debug**.
